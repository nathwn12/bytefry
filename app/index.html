Licence and attribution

Bytefry is a modified desktop build of Meme Deep Fryer, the deep-fried meme generator by Dima (dmitry.lol), published at deepfriedmemes.com and github.com/efskap/deepfriedmemes.com. The original is licensed under the GNU General Public License, version 3, and so is this build (GPL-3.0-only).

The processing pipeline is the original one: optional repeated JPEG recompression, the glfx bulge pinch, CamanJS filters, then optional repeated JPEG recompression again. The interface was rebuilt for a desktop window; the website shell, community links, analytics, advertising, service worker and absolute site paths were removed. The full licence text ships as LICENSE; changes are itemised in ATTRIBUTION.md.

Bundled: CamanJS (BSD-3-Clause, 2010 Ryan LeFevre) · glfx.js (MIT, 2011 Evan Wallace). Full notices in vendor/NOTICE. No network requests are made by this app.
